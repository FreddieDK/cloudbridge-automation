# CloudBridge Automation

Dette repository er oprettet som en del af et Proof of Concept i forbindelse med svendeprøve.

Repository'et indeholder Ansible playbooks, inventories, scripts og øvrige filer, som bruges til at teste og demonstrere automatisering i vores projektmiljø.

CloudBridge er et fiktivt virksomhedsnavn, som kun anvendes i forbindelse med projektet. Repository'et har ingen tilknytning til en virkelig virksomhed ved navn CloudBridge.
